# AICE Services — Official Website

AI + Civil Engineering solutions delivering audit-ready reports, CAD conversions, and compliant designs for ADB, World Bank, and Government of Punjab projects.

## Features
- **Modern Responsive Web Experience**: Built with React, TypeScript, and Vite.
- **Embedded AI Assistant**: Integrated text and live voice assistant powered by Google Gemini and Cloudflare Workers.
- **Interactive Solutions Showcase**: BOQ Auditor, FirstDraft AI, Report Reviewer AI, and civil engineering automation tools.

## Development

```bash
npm install
npm run dev
```
